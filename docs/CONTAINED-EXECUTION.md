# Optional contained execution

Use `homi profile preview --box` to review the optional adapter, then
`homi profile install --box` to select it. Runtime installation/startup and image
building remain explicit. Existing private account/box launchers remain usable.

The packaged [box guide](../profiles/runtime/box/README.md) documents commands,
configuration, writable mount scope, credentials, pane replies, migration paths,
and the distinction between adapter tests and actual backend qualification.
