# The phone map has moved

It ships with the `phone` plugin now, next to the skill it is the territory
for — so an agent that loads the skill gets the map with it, wherever the
plugin is installed:

- `plugins/phone/skills/phone/map.md` — the device
- `plugins/phone/skills/doordash/map.md` — DoorDash

The split is unchanged: `SKILL.md` is the method, `map.md` is what was found
by trying it.
